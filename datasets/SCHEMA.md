# Dataset provenance contract — version 1

Catalog sources include dataset id, source URL, pinned revision, license identifier,
license evidence URL/hash, retrieval date, commercial-use status and explicit production
training eligibility. Unknown, research-only or noncommercial sources stay quarantined.
A model card evaluation score is not evidence of its training-data composition.

A master JSONL recording contains: id, original_audio, original_sha256, audio,
sha256, pcm_sha256, duration_ms, channels, sample_rate, sample_width, text,
speaker, original_speaker, source_dataset, source_revision, region, locale,
kind, device, noise, banglish, transcript_status and transformation provenance.
Source speaker ids must be retained and namespaced; unknown values stay null.
Cross-dataset identity is not solved by namespacing; reviewed speaker identity links
must join groups where known. Hash equality and normalized-text/duration similarity
are separate duplicate signals; near duplicates require review, not silent deletion.

Raw source bytes/manifests are immutable. Processed WAV is mono/16kHz/PCM16;
conversion tool/version, original and resulting hashes are recorded. Exact matching
PCM hashes detect header/container changes, not all resampling/cropping transformations.
Protected FLEURS reference matches are conservatively quarantined across sources.
No duplicate detector guarantees every acoustic near-duplicate is discovered.

Every split must report kept/quarantined/duplicate recordings, speaker counts,
source counts, approximate durations and split integrity checks. Train and dev
speakers must be disjoint. No external final holdout is generated by this stage.
