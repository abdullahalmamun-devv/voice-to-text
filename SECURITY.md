# Security

This alpha has not completed the PRD's Windows runtime or stable-release acceptance tests. Avoid publishing private audio, transcripts, credentials or personal document contents in issues.

For a suspected vulnerability, open a minimal issue requesting a private reporting route without disclosing exploit details or private data. No private security address is currently configured. The application does not automatically upload reports.

Model and settings imports are local and bounded. Checksums establish integrity against a trusted manifest; they are not publisher signatures or a guarantee about arbitrary third-party models. Report the application version, operating system and a sanitized reproduction when possible.
